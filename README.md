# Teaboom.ru — карточка товара (тестовое задание)

Верстка верхней части карточки товара «Ананасовый улун» для интернет-магазина
[Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun).

## Запуск

Проект полностью статический, сборка не требуется.

1. Скачайте/склонируйте репозиторий.
2. Откройте `index.html` в браузере (двойной клик, либо через локальный сервер,
   например `npx serve .` или расширение Live Server в VS Code).

Изображение товара подключено прямой ссылкой с CDN Teaboom (`media.teaboom.ru`),
поэтому для его отображения нужен доступ в интернет.

## Структура проекта

```
teaboom-card/
├── index.html         — разметка карточки товара
├── css/
│   ├── style.css       — итоговые стили (подключены в index.html)
├── js/
│   ├── variants.js      — данные по фасовкам (вес / артикул / цена / старая цена)
│   └── script.js         — переключение фасовки, счётчик количества, кнопка «В корзину»
└── README.md
```

## Что реализовано

- Семантическая разметка: `header/main/footer`, `nav` для хлебных крошек,
  `section` для карточки, `h1`/`h2`, `role="radiogroup"` для выбора фасовки.
- Блок карточки: изображение, категория, название, выбор фасовки, артикул,
  актуальная и старая цена, скидка, счётчик количества, кнопка «В корзину»,
  короткое описание с характеристиками.
- **Переключение фасовки** (100 г / 500 г / 1000 г / 5000 г) обновляет:
  цену, старую цену, процент скидки, артикул и активное состояние кнопки —
  без перезагрузки страницы, данные лежат в `js/variants.js`.
- Итоговый счетчик при увиличении кол-ва
- Кнопка «В корзину» имеет обычное и hover-состояние, а также краткую
  текстовую обратную связь после нажатия (реальная корзина не подключалась
  по условиям задания).
- Стили — чистый CSS (Flexbox/Grid), без Bootstrap и готовых шаблонов.
  Палитра и типографика опираются на чайную тематику Teaboom
  (глубокий зелёный, тёплый нейтральный фон, акцент терракотового цвета
  для скидки), сохраняя стилистику текущего сайта.

## Адаптивность

Макет проверен на трёх ключевых ширинах:

- **Desktop (1440 px и шире)** — двухколоночная сетка: изображение слева,
  информация справа, галерея «прилипает» при скролле.
- **Tablet (768 px)** — колонки складываются в одну, изображение сверху
  ограничено по ширине, сетка фасовок и характеристик подстраивается.
- **Mobile (375 px)** — полностью одноколоночная раскладка, сетка фасовок
  2×2, кнопка «В корзину» и счётчик количества растягиваются на всю ширину
  для удобства нажатия пальцем.

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, CSS custom properties) + SCSS-исходник
- Vanilla JavaScript (без фреймворков)
- Шрифты: Manrope (заголовки) и Inter (текст) — Google Fonts
